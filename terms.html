5. Local Storage and Cloud Backup

Streaky+ primarily manages habit tracking, task information and Weekly Review functionality on the user's device.

Cloud backup is optional.

When users choose to upload a cloud backup, supported local data is packaged into an archive and transmitted to the configured cloud storage provider.

The backup may include:

  • Habit records and completion history.
  • Tasks and planning information.
  • Application settings.
  • Statistics and achievements.
  • Weekly Review records and reflections.
  • Other supported local information.

Choosing cloud backup does not necessarily provide individual record-by-record selection.

Cloud backups can therefore contain information that would otherwise remain on the device.

Streaky+ uses security measures such as encrypted network connections and account-associated access controls.

Cloud backups must not be assumed to provide end-to-end encryption.

We do not guarantee that any online storage service will be completely free from outages, technical failures or security risks.

Users should maintain independent backups of important records where appropriate.

Automatic multi-device habit synchronization is not currently provided by Streaky+.

Deleting an online Streaky+ account does not automatically erase all habits, tasks and other records stored locally on the user's phone.
